# DAEMONSPILL

> **Something escaped the system.**

DAEMONSPILL is a standalone IT-horror first-person shooter built from the GPL-released source code of **id Software's Quake**.

## Project direction

- **Origin:** [id-Software/Quake](https://github.com/id-Software/Quake)
- **Engine license:** GNU General Public License v2
- **Project:** **DAEMONSPILL**
- **Tagline:** *Something escaped the system.*
- **Goal:** A standalone IT-horror FPS with entirely original game assets.

The intended visual direction is deliberately rooted in the rough, low-poly character of 1990s shooters: server rooms, terminals, cables, corrupted systems and creatures inspired by software failures rather than by Quake's original world.

DAEMONSPILL will not depend on Quake's original proprietary game data. New maps, textures, models, sounds, music, UI artwork and other game assets are intended to be created specifically for this project.

## Upstream

This repository is a fork of the original Quake GPL source release by id Software. The original source-release notes remain available in `readme.txt`, and the GPL v2 license text is preserved in `gnu.txt`.
